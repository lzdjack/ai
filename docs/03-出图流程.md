- PC：1440 × 900，导出 2 倍（2880 × 1800）。
- 移动端：3 台手机横排画布 1440 × 1000；4 台手机横排画布 1880 × 1000（`移动端-登录`、`移动端-首次使用步骤器`）。
- 对比图：并排 3 到 4 列，上面一行亮色、下面一行暗色，每列标题写「编号 · 名称」加一句说明。

## 唯一总览集合页 index.html

```bash
python3 scripts/build-index.py   # 用模板和 docs/ 下的核心文档重新生成唯一的 index.html
```

- **单 HTML 集合约定**：项目所有供人查阅的文档（需求 `00`、修复流转 `04`、链路流转 `05`、技术设计 `06`）与双端设计图全部汇入根目录这一个 `index.html`（7 个标签页：需求、方案与链路、设计主题、PC 界面、移动端、技术设计、决策与后续），不另建分散的 HTML 页面。
- 模板写在 `scripts/index.template.html`；Markdown 文档由 `scripts/build-index.py` 自动转换，技术方案里的架构 / ER / 状态机图由 `scripts/tech_diagrams.py` 渲染为自适应亮/暗的内联 SVG（完全离线可用）。
- 设计图通过 `reference/images/` 的相对路径引用，亮色和暗色两版图片会跟着页面主题切换。
- PC 和移动端图上的红色编号写在模板末尾 `annotate(...)` 的参数里：`[x%, y%, 标题, 说明]`。编号要放在区块边缘，不要压住文字。
